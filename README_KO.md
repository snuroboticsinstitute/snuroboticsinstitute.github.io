## 작업 범위
국·영문 콘텐츠와 메뉴 구조, 기존 기능을 유지하고 디자인을 개편합니다.
PC와 모바일 화면을 함께 디자인해 주세요. 본문 가독성을 확보하고 제목의 위계,
여백과 탭 표시를 일관되게 적용해 주세요. 원래 약어를 제외한 영문 전체 대문자와
좁은 자간은 피합니다. 교수·연구실 인원수를 크게 강조하지 않습니다.

## 파일 구성
- dist/: 현재 공개 사이트의 완전한 정적 HTML 소스 및 실행 파일입니다. 이 폴더를 웹 루트로 서비스합니다.
- dist/en/: 영문 페이지
- dist/assets/: CSS, JavaScript, 이미지, 로고, 폰트, 검색 데이터 등 공용 자료
- scripts/: 콘텐츠 데이터(JSON), 페이지 생성·갱신용 Python 스크립트 및 뉴스레터 원본
- .openai/hosting.json: 기존 Sites 배포 설정 참고용. 다른 호스팅에서는 필요하지 않습니다.
- FILE_MANIFEST.txt: 포함 파일 목록

현재 페이지는 HTML/CSS/JavaScript로 만들어져 있으며 npm 설치나 빌드 없이 실행됩니다.
수작업으로 세부 수정된 dist/가 현재 공개 화면의 기준입니다. scripts/는 보조 자료입니다.
특히 build-english.py 등 기존 생성 스크립트를 일괄 실행하면 세부 수정 내용이 덮어써질 수 있으므로,
재디자인은 먼저 dist/ 복사본에서 작업하고 필요한 생성 스크립트만 검토 후 수정해 주세요.

## 로컬 확인
Python 3 설치 후 압축 해제한 프로젝트 폴더에서:

    python -m http.server 8000 --directory dist

브라우저 주소:
- 국문: http://localhost:8000/
- 영문: http://localhost:8000/en/

HTML을 더블클릭하는 file:// 방식 대신 위처럼 서버를 사용하세요.
루트 기준 경로(/assets/ 등)를 사용하므로 dist/를 반드시 웹 루트로 설정합니다.
다른 정적 웹서버도 사용할 수 있습니다. 서버 종료는 Ctrl+C입니다.

## 주요 메뉴와 유지할 동작
- 소개: 한눈에 보기, 소장 인사말, 비전, 연혁, 오시는 길
- 소식: 전체 소식과 분류 탭, 검색, 뉴스 상세, 목록형 뉴스레터
- 연구: 연구사업 → 국가연구소(NRL 2.0)
- 국가연구소: 소개(첫 화면), 핵심기술, 프로젝트 그룹, 참여교수, 연계교수
- 교육: 창의공학설계
- 구성원: 겸무교수, 박사후 연구원, 운영진, 테크니컬 스태프, 행정실
- 참여하기: 현재 페이지 내 항목 및 연결 유지
- 국·영문 전환, 두 가지 색상 테마, 모바일 메뉴, 홈페이지 검색
- 교수 이름·소속·연구실 검색, TC/PG 필터와 연구그룹↔교수 상호 링크
- 겸무교수 목록의 새로고침 시 무작위 정렬
- 대학 로고의 해당 언어 홈 링크, 홈 국가연구소 로고의 NRL 소개 링크
- 홈 뉴스·바로가기, 푸터 연락처 및 SNS 링크
